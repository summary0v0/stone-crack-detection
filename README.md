# 石材裂纹检测

选择本机石材图片，检测裂纹并保存结果。

## 1. 首次安装

需要 **Windows 64 位系统和网络连接**，无需提前安装 Python 或 PyTorch。

1. 将项目解压到准备长期使用的文件夹。
2. 双击 **`安装环境.cmd`**。
3. 等待窗口显示 **“环境安装成功”**。首次需要下载约 2.7 GB，请耐心等待。

如需使用 NVIDIA 显卡加速，请先安装对应的显卡驱动。没有 NVIDIA 显卡也可以使用 CPU 检测。

## 2. 开始检测

1. 双击 **`启动石材裂纹检测.cmd`**。
2. 点击 **“选择图像”**，选择待检测图片。
3. 检测设备保留 **“自动选择”**，点击 **“开始检测”**。
4. 完成后查看结果，点击 **“打开结果文件夹”** 获取保存的图片。

以后使用时直接启动检测程序，不需要重复安装环境。安装完成后，请保留程序自动生成的文件夹。

## 3. 模型基本结构与原理

### 模型与任务

本项目使用 **CrackFormer-II** 网络，加载 **Stone331 石材裂纹权重** `crackformer_ii/weights/stone.pth`。权重文件大小为 **20,170,079 字节，约 20.17 MB（19.24 MiB）**；文件大小不等于运行时显存占用。

它属于**裂纹语义分割模型**：对图像中的每个像素预测裂纹概率，形成裂纹区域掩膜。它不是 Mask R-CNN，不包含目标候选框和 ROI 实例分割流程，也不直接给出每条裂纹的独立编号、数量或物理宽度。

### 整体结构

网络采用**五级编码器—解码器结构**，结合卷积、注意力和多尺度融合。以下尺寸以单张 `512 × 512` 三通道图像为例，依据本项目保存的网络源码整理：

| 部分 | 特征尺寸与通道 | 主要作用 |
| --- | --- | --- |
| 输入 | `3 × 512 × 512` | 接收石材图像 |
| 编码第 1 级 | `64 × 512 × 512`，池化后为 `64 × 256 × 256` | 提取边缘、纹理等浅层特征 |
| 编码第 2 级 | `128 × 256 × 256`，池化后为 `128 × 128 × 128` | 组合局部结构 |
| 编码第 3 级 | `256 × 128 × 128`，池化后为 `256 × 64 × 64` | 提取更大范围的裂纹特征 |
| 编码第 4 级 | `512 × 64 × 64`，池化后为 `512 × 32 × 32` | 聚合深层上下文 |
| 编码第 5 级 | `512 × 32 × 32`，池化后为 `512 × 16 × 16` | 获得最深层特征 |
| 五级解码器 | 逐级恢复到 `512 × 512`；各级输出通道依次为 `512、256、128、64、64` | 利用池化位置索引反池化，再细化特征 |
| 多尺度融合与输出 | 五张全分辨率单通道预测图 → 一张单通道输出 | 汇合不同尺度的信息 |

整体数据流如下：

```text
三通道图像
    ↓
五级编码：卷积 / Transformer 特征块 + 最大池化（保存位置索引）
    ↓
五级解码：使用对应索引最大反池化 + Transformer 特征块
    ↓
各尺度编码 / 解码特征 → LABlock 注意力门控 → Fuse 融合
    ↓
五张尺度预测图统一到输入分辨率 → 拼接 → 1×1 卷积
    ↓
单通道 logits → Sigmoid → 裂纹概率图 → 阈值化 → 裂纹掩膜
```

### 关键模块如何工作

1. **卷积与 Transformer 特征块**：入口通过 `3×3` 卷积提取特征，后续主要使用 `Trans_EB`。其中的瓶颈结构先用 `1×1` 卷积压缩通道，再执行 `TFBlock`，最后恢复通道，并通过残差连接保留输入信息。`TFBlock` 包含注意力分支和卷积式 MLP 分支；MLP 使用 `1×1` 卷积、`3×3` 分组卷积、GroupNorm 和 GELU。
2. **内容信息与局部上下文结合**：`LocalSABlock` 从特征中生成 Query、Key、Value。一条分支在当前特征图的全部空间位置聚合内容信息，另一条分支通过可学习的 `7×7` 邻域嵌入提取局部上下文，两者相加输出。这样既能利用较大范围的信息，也能保留细小裂纹周围的纹理线索。这里的全局范围是当前输入图块，不能跨越独立推理的图块。
3. **保留位置的下采样与恢复**：编码阶段使用最大池化缩小特征图，并保存最大值位置；解码阶段使用对应索引进行最大反池化，再通过特征块细化。反池化提供位置线索，但不保证自动恢复所有丢失的细节。
4. **注意力门控与多尺度融合**：`LABlock` 将同尺度的若干编码、解码中间特征相加，通过卷积和 Sigmoid 生成权重。`Fuse` 拼接该尺度的编码与解码特征，压缩到 64 通道，乘以注意力权重，再生成单通道预测图。五个尺度的预测图经双线性插值统一到输入大小，最终通过 `1×1` 卷积融合。

网络返回 **5 张尺度输出和 1 张最终融合输出**，均为未经 Sigmoid 的 logits。本项目推理程序取最后一张输出，经过 Sigmoid 转换为 `0～1` 的裂纹概率。

### 本项目如何生成检测结果

- **预处理**：默认保持 OpenCV 的 BGR 通道顺序，将 8 位像素除以 255，转换为三通道浮点输入；启用灰度选项时先转为灰度，再复制为三通道。
- **大图切块**：默认使用 `512 × 512` 图块，相邻图块重叠 64 像素；小于图块尺寸的边缘用复制边界补齐。重叠区域的预测概率取平均，最后裁回原图尺寸。
- **阈值分割**：默认阈值为 `0.5`，概率大于或等于阈值的像素标记为裂纹。降低阈值通常会增加检出区域，也可能增加误检；提高阈值通常会减少检出区域，也可能漏掉较弱裂纹。
- **保存结果**：输出浮点概率数组（`.probability.npy`）、概率灰度图（`.probability.png`）、二值掩膜（`.mask.png`）和红色叠加图（`.overlay.png`），保存在 `crackformer_ii/outputs/` 下。掩膜中白色为预测裂纹，黑色为背景。

权重加载前校验 SHA-256，并使用 `strict=True` 严格匹配网络参数。当前能力是石材裂纹分割；天然纹理、接缝和标记等仍可能造成误检，实际精度需要使用带标注的现场图像评估。CPU 功能验证不代表 RTX 4060 实机 CUDA 验证或识别精度达标。

## 遇到问题

- **安装失败**：检查网络后重新运行 `安装环境.cmd`。仍然失败时，将安装窗口中的错误信息交给维护人员。
- **GPU 检测失败**：先选择“本机 CPU”使用，再检查显卡驱动。

**换电脑时**：不复制旧的 `.python`、`.venv` 和 `.tools` 文件夹；保留其余项目文件，在新电脑重新双击 `安装环境.cmd` 安装。
